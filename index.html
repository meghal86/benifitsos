01 · Dependent Eligibility Audit

Verify every dependent before renewal starts.

BenefitsOS imports the roster, runs risk scoring, automates outreach, reads documents with Claude Vision, routes exceptions to broker review, and creates the savings report.

Output Clean census, ineligible dependents removed, audit report ready for the CFO.
End-to-end process
Step 1 — Data intake

Upload your roster.
We handle the risk scoring.

Connect ADP via API or drop a CSV. BenefitsOS imports the full dependent roster, immediately risk-scores every dependent — age violations, address mismatches, enrollment anomalies — and cross-checks against USPS and the SSA Death Master File before a single email is sent.

See the intake engine →
Step 2 — Automated outreach

Six waves.
Zero manual work.

Inngest orchestrates email, SMS, physical mail, HR escalation, and a termination notice — automatically. Every wave is personalised. Real-time tracking. The sequence stops the moment an employee completes verification.

View the outreach flow →
Step 3 — AI verification

Claude reads every document.
In seconds.

Claude Vision extracts names, dates, and relationships from birth and marriage certificates. Fraud detection runs metadata analysis plus visual pixel inspection. High-confidence cases auto-resolve. Low-confidence cases route to the broker review queue.

Read the technical docs →
Step 4 — Report + billing

You review edge cases.
We handle everything else.

Low-confidence documents land in your review queue with the original image and AI-extracted data side by side. When the audit closes, the savings report PDF generates automatically and Stripe invoices the employer.
